# Design brief — Soft Paper (portfolio UI)

| Item | Choice |
|------|--------|
| Screens | Dashboard `/` + Review `/review/[jobId]` |
| Impression | Soft Paper — practical, editorial, light |
| Density | 4 (airy but tool-like) |
| Light/dark | Light only |
| Font | IBM Plex Sans JP |
| Icons | None added (type + rules only) |
| Signature | Left ink rule on primary sections; hairline dividers |
| Demo assets | `frontend/public/demo/*.png` → `/demo/...` in Mock fixtures |
