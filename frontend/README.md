# Frontend (Next.js)

SmartResearch-HQ dashboard and review UI. **Project overview, setup, and deploy:** see the [repository README](../README.md).

---

## Quick start (portfolio)

From the repo root:

```bash
bash scripts/bootstrap-local.sh
cd frontend && npm run dev
```

Set `NEXT_PUBLIC_API_URL` in `.env.local` (generated by bootstrap), e.g. `http://localhost:8000/api/v1`.

```bash
npm run lint
npm run build
```

## E2E (Playwright)

See **[e2e/README.md](./e2e/README.md)**. From repo root: `bash scripts/run-frontend-e2e.sh`.
